## Base de datos de Notion

El sistema utiliza una estructura de datos dividida en tres bases relacionadas:

- Prospectos: información de los potenciales clientes y sus necesidades.
- Propuestas: propuestas generadas y estado de aprobación.
- Logs: errores y eventos registrados durante las ejecuciones.
